## Cómo se carga una clase nueva

1. Copiar [`_plantilla-clase.md`](_plantilla-clase.md) a `clase-NN-tema.md`.
2. Completar las secciones. **La sección obligatoria es "Aplicación a FraudLens"**: una clase sin
   bajada a nuestro proyecto no sirve de nada.
3. Agregar los términos nuevos al [glosario](../00-proyecto/glosario.md), marcados ✅ y con la clase de origen.
4. Cargar en "Qué tenemos que hacer para la próxima" las tareas concretas → llevarlas al Trello.
5. Agregar la fila al índice de arriba.
6. Registrar la sesión en [`bitacora/`](../../bitacora/) y el aporte en
   [`registro/historial-aportes.md`](../../registro/historial-aportes.md).
