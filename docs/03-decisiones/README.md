# Decisiones

Registro numerado de las decisiones del equipo. Cada decisión es un archivo, con contexto,
alternativas y consecuencias.

## Por qué

Para que dentro de dos meses, cuando alguien pregunte *"¿por qué habíamos elegido esto?"*, la
respuesta esté escrita y no dependa de la memoria de quien estuvo en esa charla. También sirve
directamente para el documento entregable: **el docente evalúa el cumplimiento problema-solución**,
y eso se defiende mostrando el razonamiento.

## Reglas

- **Se numeran correlativamente**, con cuatro dígitos: `0003-titulo-corto.md`.
- **No se editan las decisiones viejas.** Si cambiamos de opinión, se escribe una decisión nueva que
  la **supersede**, y en la vieja se agrega una línea apuntando a la nueva.
- Estados: `🟡 Propuesta` · `✅ Aceptada` · `❌ Rechazada` · `⛔ Superseded por NNNN`
- Si la decisión sale de responder una [pregunta abierta](../00-proyecto/preguntas-abiertas.md),
  se linkean entre sí.
