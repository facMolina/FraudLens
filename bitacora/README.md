# Bitácora

Un archivo por sesión de trabajo. Una "sesión" es cualquier rato en que se trabajó en el proyecto:
una clase, una reunión de equipo, o dos horas de alguien solo un martes a la noche.

## Nombre de archivo

```
AAAA-MM-DD-descripcion-corta.md
```

Ejemplos: `2026-09-08-clase-02.md`, `2026-09-15-definicion-de-target.md`

Si hay dos sesiones el mismo día, se agrega sufijo: `-a`, `-b`.

## Para qué sirve

Para poder reconstruir **qué se hizo, cuándo y con quién** sin depender de la memoria. En las
Sprint Reviews y en las retrospectivas es la fuente para contar el avance, y en la entrega final
es la evidencia de que el trabajo fue sostenido y no de la última semana.
